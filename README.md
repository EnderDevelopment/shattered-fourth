# Minecraft Dimension Mod: The Shattered Fourth

The Shattered Fourth is a Fabric Minecraft dimension mod for Minecraft 1.21.1. It adds a custom dimension, Starforged weapons and armor, and an Oath Sigil that lets players serve a living entity marked as the realm’s deity.

## Install

1. Install Minecraft 1.21.1 with Fabric Loader and Fabric API.
2. Build the mod with `./gradlew build`, or obtain its built JAR.
3. Place the JAR in the Minecraft `mods` folder.
4. Launch the game with the Fabric profile.

## Use

1. Enter the dimension with the operator command `/execute in fourth_realm:aether run tp @s 0 160 0`.
2. Equip Starforged gear or obtain it from the Creative inventory’s Combat tab. The Oath Sigil is in the Ingredients tab.
3. Use the Oath Sigil on a living entity tagged `fourth_realm.deity` to serve it. The entity receives the `fourth_realm.served` tag, and the sigil is consumed.
4. Fall below Y=-32 in the dimension to return to the Overworld at Y=180.
